# ระบบจัดทำรายงานภาพถ่ายสำรวจที่ดิน (A4 Survey Photo Reporter)

เว็บแอปพลิเคชันแบบ **Mobile-First Static Web Application** ไฟล์เดียว (`index.html`) สำหรับจัดทำรายงานภาพถ่ายสำรวจที่ดินลงบนหน้ากระดาษมาตรฐาน A4 แนวตั้ง ความละเอียดสูง **200 DPI (1654 x 2339 พิกเซล)** พร้อมระบบบีบอัดภาพเพื่อความปลอดภัยของหน่วยความจำมือถือ และสามารถนำขึ้นใช้งานบน **GitHub Pages** ได้ทันทีโดยไม่ต้องมี Backend หรือฐานข้อมูล (Zero Backend 100% Client-side)

---

## 🌟 คุณสมบัติเด่น (Key Features)

### 1. ส่วนหัวและระบบบันทึกสถานะอัตโนมัติ (Header & Local State Persistence)
* **ชื่องาน (Project Name):** ระบุชื่องานหรือชื่อโครงการสำรวจ เช่น ระบบโครงข่ายไฟฟ้า ....
* **เลขแปลงที่ดิน (Land Parcel Number):** ระบุหมายเลขแปลงที่ดิน เช่น `A001` หรือ `B001`
* **Auto-Save ในตัว:** บันทึกข้อมูลชื่องานและเลขแปลงลงใน `localStorage` ของเบราว์เซอร์อัตโนมัติ สลับไปเปิดแอปกล้องหรือแอปแผนที่แล้วกลับมาข้อมูลไม่สูญหาย
* **ปุ่ม "เริ่มแปลงถัดไป (คงชื่องานเดิม)":** ล้างเฉพาะรูปภาพ เลขแปลงที่ดิน และการตั้งค่าหน้ากระดาษ โดยยังคง "ชื่องานเดิม" ไว้ เพื่อความรวดเร็วในการสำรวจแปลงต่อเนื่อง

### 2. ระบบบีบอัดภาพทันทีเพื่อความปลอดภัยของมือถือ (Memory-Safe Immediate Compression)
* รองรับการอัปโหลดไฟล์ภาพ `.jpg`, `.jpeg`, `.png`, และ `.gif` (เลือกหลายภาพพร้อมกัน และสามารถกดเพิ่มภาพต่อยอดได้ตลอดเวลา)
* **ประมวลผลทีละภาพทันที (One-by-one Asynchronous):** บีบอัดลดขนาดภาพทันทีที่เลือก โดยย่อด้านยาวสุดเหลือไม่เกิน **1600 px** (เฉพาะภาพที่ใหญ่กว่า) ที่คุณภาพ JPEG **0.85** ด้วย HTML5 Canvas พร้อมปลดปล่อยหน่วยความจำ (Revoke Object URL & Wipe Canvas) ทันที ป้องกันเบราว์เซอร์มือถือ (iOS Safari / Android Chrome) ค้างหรือแครช
* **แถบสรุปการบีบอัด (Compression Summary Badge):** แสดงผลเปรียบเทียบขนาดไฟล์จริงก่อนและหลังบีบอัดแบบเรียลไทม์ เช่น `ขนาดต้นฉบับรวม: 48.2 MB → หลังบีบอัด: 4.1 MB (ประหยัดพื้นที่ 91.5%)`

### 3. จัดการภาพ จัดเรียงเวลา และแท็กด่วน (Photo Controls & Quick Tags)
* **Silent EXIF Timestamp Reading:** อ่านเวลาถ่ายภาพต้นฉบับ (`DateTimeOriginal`) ผ่าน `exifr` อย่างเงียบๆ เพื่อใช้สำหรับเรียงลำดับเวลา (หากไม่มีจะใช้เวลาแก้ไขไฟล์ล่าสุด) **โดยไม่แทรกวันที่หรือพิกัดลงในแคปชัน**
* **ปุ่ม "เรียงตามเวลาถ่ายภาพอัตโนมัติ":** จัดเรียงภาพทั้งหมดจากเก่าสุดไปใหม่สุดในคลิกเดียว
* **การควบคุมแต่ละการ์ดภาพ:**
  * **หมุนภาพ (Rotate 90°):** หมุนภาพตามเข็มนาฬิกาทีละ 90 องศา
  * **สลับลำดับ (⬅️ / ➡️):** เลื่อนลำดับภาพขึ้น-ลง หรือ ซ้าย-ขวา
  * **ลบภาพ (ลบ):** ลบภาพที่ไม่ต้องการออก
  * **ปุ่มแท็กด่วนหลายรายการ (Multi-Select Quick Tags):** ปุ่มกด 3 ตัวเลือก ได้แก่ **`ที่ดิน`**, **`ต้นไม้`**, และ **`อาคารสิ่งปลูกสร้าง`** กดเพื่อเปิด/ปิด และระบบจะอัปเดตข้อความในกล่องคำอธิบายให้อัตโนมัติ (เช่น เลือกทั้งต้นไม้และอาคารสิ่งปลูกสร้าง จะได้ `ต้นไม้, อาคารสิ่งปลูกสร้าง`)
  * **คำอธิบายใต้ภาพ (Editable Caption):** เริ่มต้นเป็นค่าว่าง สามารถพิมพ์ข้อความเพิ่มเติมหรือแก้ไขได้อย่างอิสระ

### 4. การจัดหน้ากระดาษ A4 แบบไหลเลื่อนต่อเนื่อง (Cascading Per-Page A4 Layout)
* เรนเดอร์หน้ากระดาษ A4 แนวตั้ง ความละเอียด **200 DPI (`1654 x 2339 px`)** คมชัดระดับส่งพิมพ์
* **ค่าเริ่มต้น:** จัดหน้าแบบมาตรฐาน **4 รูป/หน้า (ตาราง 2x2)**
* **ปุ่มปรับโควตารายหน้าอิสระ:** แต่ละหน้ามีปุ่มเลือก `[ 2 รูป/หน้า (ภาพใหญ่) | 4 รูป/หน้า (มาตรฐาน) ]`
* **ระบบไหลเลื่อนอัตโนมัติ (Cascading / Reflow):** เมื่อเปลี่ยนโควตาของหน้าใดๆ รูปภาพที่เหลือจะไหลเลื่อนจัดหน้าถัดไปให้อัตโนมัติโดยยังคงลำดับภาพเดิมไว้ 100%
* **โครงสร้างหัวกระดาษ A4 ทุกหน้า:**
  * บรรทัดที่ 1 (ตัวปกติ ~28px Sarabun): `ชื่องาน: [Project Name]`
  * มุมขวาบน (~24px Sarabun): `หน้า [Current]/[Total]`
  * บรรทัดที่ 2 (ตัวหนา เด่นชัด ~46px Sarabun): `เลขแปลงที่ดิน: [Land Parcel Number]`
  * เส้นคั่นแนวนอนคมชัดใต้หัวกระดาษ
* **การแสดงผลรูปภาพในหน้า A4:** รักษาอัตราส่วนของภาพ (Aspect Ratio) ไม่มีการยืด หด หรือครอบตัดภาพ พร้อมคำอธิบายใต้ภาพฟอนต์ Sarabun กึ่งกลาง

### 5. ตัวอย่างเสมือนจริงและโหมดตรวจสอบเต็มจอ (Live Preview & Fullscreen Lightbox)
* แสดงตัวอย่างหน้าเอกสาร A4 ทุกหน้าแบบเรียลไทม์บนหน้าจอ
* แตะ/คลิกที่หน้ากระดาษเพื่อเปิด **Fullscreen Lightbox** ตรวจสอบความคมชัด ซูมเข้า ซูมออก และเลื่อนเปลี่ยนหน้าตรวจดูรายละเอียดได้ทันที

### 6. การส่งออกและสั่งพิมพ์ (Filename Confirmation, Export & Print)
* **ปุ่ม "สั่งพิมพ์ทันที" (`window.print()`):** กำหนด CSS `@media print` จัดพิมพ์หน้าละ 1 แผ่น A4 พอดี ซ่อนแถบเมนูและปุ่มควบคุมทั้งหมด
* **หน้าต่างยืนยันชื่อไฟล์ (Filename Confirmation Modal):**
  * แสดงก่อนดาวน์โหลด PDF หรือ JPG
  * ค่าเริ่มต้นชื่อไฟล์: `รูปภาพแปลง_[เลขแปลงที่ดิน]` (ไม่มีชื่องาน) เช่น แปลง `A001` จะได้ `รูปภาพแปลง_A001`
  * กรองอักขระพิเศษที่ไม่ถูกต้อง (`/ \ : * ? " < > |`) เป็นเครื่องหมายขีดกลาง `-` อัตโนมัติ (เช่น แปลง `A001/1` จะได้ `รูปภาพแปลง_A001-1`)
  * หากไม่ได้ระบุเลขแปลง จะใช้ `รูปภาพแปลง_ไม่ระบุ`
  * แสดงขนาดไฟล์โดยประมาณ และอนุญาตให้ผู้ใช้แก้ไขชื่อไฟล์ได้ก่อนกดยืนยัน
* **ส่งออก PDF:** สร้างไฟล์มัลติเพจ A4 Portrait PDF ผ่าน `jsPDF`
* **ส่งออก JPG:** หากมี 1 หน้าจะดาวน์โหลด `.jpg` ทันที หากมีหลายหน้าจะรวมไฟล์เข้า `.zip` ผ่าน `JSZip`

## 🚀 ขั้นตอนการติดตั้งและเปิดใช้งานบน GitHub Pages

เนื่องจากแอปพลิเคชันนี้ทำงานแบบ **Client-side 100%** ผ่านไฟล์ `index.html` เพียงไฟล์เดียว คุณสามารถนำขึ้นใช้งานบน GitHub Pages ได้ฟรีภายใน 2 นาที:

### วิธีที่ 1: อัปโหลดผ่านหน้าเว็บไซต์ GitHub (ง่ายที่สุด ไม่ต้องลงโปรแกรม)

1. เข้าเว็บไซต์ [GitHub.com](https://github.com) แล้วเข้าสู่ระบบ
2. กดปุ่ม **New** (หรือเครื่องหมาย `+` มุมขวาบน) เพื่อสร้าง Repository ใหม่:
   * ตั้งชื่อ Repository เช่น `land-survey-report`
   * เลือกเป็น **Public**
   * ติ๊กถูกที่ **Add a README file** (หรือไม่ติ๊กก็ได้)
   * กดปุ่ม **Create repository**
3. ในหน้า Repository ที่สร้างเสร็จ:
   * กดปุ่ม **Add file** -> เลือก **Upload files**
   * ลากไฟล์ `index.html` และ `README.md` ไปวางในช่องอัปโหลด
   * กดปุ่มสีเขียว **Commit changes**
4. เปิดการทำงานของ GitHub Pages:
   * ไปที่แท็บ **Settings** ของ Repository
   * เมนูด้านซ้าย เลือกหัวข้อ **Pages**
   * ใต้หัวข้อ **Build and deployment**:
     * Source: เลือก **Deploy from a branch**
     * Branch: เลือก branch **`main`** และโฟลเดอร์ **`/(root)`**
     * กดปุ่ม **Save**
5. รอระบบประมวลผลประมาณ 30-60 วินาที ระบบจะแสดงลิงก์เว็บไซต์ของคุณด้านบน เช่น:
   `https://<your-username>.github.io/land-survey-report/`
6. เปิดลิงก์ดังกล่าวบนมือถือหรือคอมพิวเตอร์เพื่อเริ่มใช้งานได้ทันที!

---

### วิธีที่ 2: อัปโหลดผ่าน Git Command Line

หากคุณติดตั้ง Git บนเครื่องคอมพิวเตอร์ สามารถรันคำสั่งต่อไปนี้ในโฟลเดอร์โปรเจกต์:

```bash
# 1. กำหนดค่า Git ในโฟลเดอร์
git init
git add index.html README.md
git commit -m "Initial commit: Production-ready land survey photo reporter"

# 2. เชื่อมต่อไปยัง GitHub Repository ของคุณ (เปลี่ยน URL เป็นของคุณ)
git branch -M main
git remote add origin https://github.com/<your-username>/land-survey-report.git

# 3. อัปโหลดไฟล์ขึ้น GitHub
git push -u origin main
```

จากนั้นไปที่ **Repository Settings** -> **Pages** -> เลือก Branch `main` โฟลเดอร์ `/(root)` แล้วกด **Save** ตามขั้นตอนในวิธีที่ 1

## 📱 เทคนิคการติดตั้งลงหน้าจอมือถือ (Add to Home Screen)

เพื่อให้ใช้งานภาคสนามได้สะดวกรวดเร็วเหมือนแอปพลิเคชันมือถือทั่วไป:

### สำหรับ iPhone / iPad (Safari):
1. เปิดลิงก์ GitHub Pages ในเบราว์เซอร์ **Safari**
2. กดปุ่ม **แชร์ (Share)** (ไอคอนสี่เหลี่ยมมีลูกศรชี้ขึ้นที่แถบด้านล่าง)
3. เลื่อนลงแล้วเลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
4. ตั้งชื่อไอคอนตามต้องการ แล้วกด **"เพิ่ม" (Add)**

### สำหรับ Android (Google Chrome):
1. เปิดลิงก์ GitHub Pages ในเบราว์เซอร์ **Google Chrome**
2. กดปุ่ม **เมนู 3 จุด (⋮)** ที่มุมขวาบน
3. เลือก **"เพิ่มลงในหน้าจอหลัก" (Add to Home screen)** หรือ **"ติดตั้งแอป" (Install App)**
4. กดยืนยันเพื่อสร้างไอคอนลัดบนหน้าจอมือถือ

## 🛠️ เทคโนโลยีและไลบรารีที่ใช้ (Technology Stack)

* **Tailwind CSS (via CDN):** ออกแบบ UI สไตล์ Modern Clean แบบ Mobile-First ตอบสนองทุกขนาดหน้าจอ
* **Google Fonts (Sarabun):** ฟอนต์ภาษาไทยมาตรฐาน รองรับสระ วรรณยุกต์ และตัวเลขชัดเจน
* **exifr (v7.1.3 via CDN):** อ่านข้อมูลเมทาดาต้า EXIF `DateTimeOriginal` ของรูปถ่ายเพื่อใช้เรียงลำดับเวลาอย่างมีประสิทธิภาพ
* **HTML5 Canvas API:** คำนวณอัตราส่วนภาพ บีบอัดลดขนาดภาพ และเรนเดอร์หน้ากระดาษ A4 200 DPI (`1654 x 2339 px`)
* **jsPDF (v2.5.1 via CDN):** ประมวลผลและสร้างไฟล์ PDF ขนาด A4 แนวตั้งหลายหน้าแบบสมบูรณ์
* **JSZip (v3.10.1 via CDN):** รวมไฟล์รูปภาพ A4 JPG หลายหน้าเข้าเป็นไฟล์ ZIP ไฟล์เดียวสำหรับดาวน์โหลด

## 🔒 ความปลอดภัยและความเป็นส่วนตัว (Privacy & Security)

* **Zero Backend:** ทุกการประมวลผล (การย่อรูป การหมุนภาพ การเรียงลำดับ การแปลง PDF/JPG) ทำงานบนเครื่องของผู้ใช้ (Client-Side Memory) 100%
* **ไม่มีการส่งภาพขึ้น Cloud:** ภาพถ่ายสำรวจ แปลงที่ดิน และข้อมูลชื่องานจะไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์ภายนอกใดๆ ทั้งสิ้น ข้อมูลมีความปลอดภัยและเป็นความลับตามมาตรฐานงานสำรวจ
